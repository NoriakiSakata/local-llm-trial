# ローカルLLMレビュアー

ローカルLLM（OpenAI互換API）にPRを読ませて、PR全体の所感と行ごとの指摘をレビューコメントとして付ける仕組みです。
非公開のリポジトリで、セルフホストランナー（LLMのAPIにつながる手元のMac）を使い、Flutterアプリを題材に試しました。

このフォルダのファイルは参考用に置いているだけで、このリポジトリでは動きません。

## 動き

1. PRにラベルを付ける。`ai-review` なら情報を足したレビュー、`ai-review-basic` なら差分だけのレビュー
2. セルフホストランナー上でPRの内容を集めて、LLMに渡す
3. 指摘（最大6件）を行ごとのコメントとして付ける。承認はしない
4. 終わったらラベルを外す（付け直せばもう一度レビュー）

情報を足したレビューでは、差分に加えて次のものを渡します。

| 渡すもの | 取り方 |
|---|---|
| プロジェクトのルール | `.github/ai-review.md` |
| ファイル一覧 | `lib/` 以下 |
| 変更したファイルの全文 | 800行まで |
| 変更したメソッドなどの参照箇所 | `lib/` と `test/` を grep |
| 関連するイシュー | PRの説明にある `#番号` |
| 静的解析とテストの結果 | `fvm flutter analyze` と `fvm flutter test` |

lockファイルや自動生成ファイルは対象外です。差分が大きすぎるPRはスキップします。

## 使い方

| ファイル | 置き場所 |
|---|---|
| `ai-review.yml` | `.github/workflows/ai-review.yml` |
| `ai_review.py` | `.github/scripts/ai_review.py` |
| `ai-review.md` | `.github/ai-review.md`（ルールの例。プロジェクトに合わせて書き換える） |

リポジトリのSecretsに次の3つを登録します。

| Secret | 内容 |
|---|---|
| `LLM_BASE_URL` | OpenAI互換APIのベースURL（`/v1` まで） |
| `LLM_API_KEY` | APIキー |
| `LLM_MODEL` | モデル名 |

スクリプトはPython標準ライブラリと `gh` コマンドだけで動きます（Python 3.9以上）。
`lib/`、`test/`、`fvm flutter` の部分はFlutterのプロジェクト向けなので、ほかの言語で使うときは書き換えてください。

レビュー用のスクリプトとルールは、PR側ではなくベースブランチのものを使います（PRで書き換えられないようにするため）。

## 注意

**公開リポジトリでは、セルフホストランナーを使わないでください。**
外部の人がPRでワークフローを書き換えると、ランナーのマシン上で任意のコードが動く可能性があります。非公開リポジトリで使ってください。
